# 0.1.19-preview：百度同目录字幕 HTTP 403

2026-10-14。用户提供百度字幕选择与错误截图，并确认影片为《希望》。测试在保留用户登录配置的 Android TV 11 / API 30 模拟器完成，未连接真实电视。

## 问题及修复

旧版使用视频原文件的 DLNA 下载地址读取百度同目录字幕。测试账号中文 ASS 文件在六种普通请求头／Range 组合中均返回 HTTP 403，服务代码 31329；并非文件没有字幕或中文字幕编码不可识别。使用当前正常网页登录会话提供的文件下载流程后，同一份文件返回 HTTP 200。

百度字幕现在单独取得所选文件的元数据及当前会话签名参数，再请求该文件的正常下载地址。校对路径、文件 ID、目录标记和文件大小，下载地址限定为 HTTPS 的百度官方域名。请求没有覆盖会员等级的参数；签名参数仅在本机本次会话中使用，不执行服务器提供的 JavaScript，不内置账号凭据。原视频下载、播放、其他网盘字幕以及现有本地字幕解码保持原流程。

## 同片同文件验证

测试环境旧影片索引只收录一份百度 ASS 字幕。重新读取实际网盘目录后，在“希望 HOPE (2026)”找到用户所说的“简中.srt”，87,745 bytes。

| 检查 | 结果 |
| --- | --- |
| 公开 0.1.18 读取同一份“简中.srt” | 字幕下载失败；与用户截图相同的失败步骤 |
| 修复版完整下载、UTF-8 缓存 | 87,745 bytes；有效 SRT 时间轴，通过 |
| Media3 实际解析 | 1,419 个时间段；包含 129 个较长的中文时间段 |
| 播放器实际字幕选择菜单 | 用户同样的“选择网盘字幕”入口，选中后添加真实文件成功 |
| 画面显示 | 首帧、可解码的视频轨道、所选文字轨道及可见中文字幕均通过；截图人工检查通过 |
| 显示内容与时间轴 | 与原字幕解析结果及当前播放时间一致，通过 |
| 中段快进 | 中文内容随播放位置变化，与字幕时间轴对应，通过 |
| 加载后继续播放 | 时间持续前进，没有因添加字幕停止播放，通过 |
| 关闭字幕 | 轨道禁用，当前文字清除，不自动重开，通过 |
| 重新选择 | 重新获取下载地址、缓存文件并显示中文字幕，通过 |
| 真实 ASS 旁挂字幕 | 107,489 bytes；完整下载、966 个解析时间段、实际中文字幕显示通过 |
| 自动化检查 | 195 项；193 通过、2 项既有跳过、0 失败、0 错误 |
| Android lint | 0 错误；54 条既有警告 |

早期 ASS 显示测试用原始 Dialogue 行预测中文时间，字段中可能包含中文样式名称，不能据此确认实际中文对白；改为使用 Media3 解析出的真实中文 Cue 时间后显示通过。原始失败日志保留，不将它们改写成通过。SRT 最终测试同时核对实际 Cue、原文件时间段和当前播放器位置，避免仅凭轨道被选中就判定字幕显示成功。

字幕内容、用户网盘路径、完整下载地址、会话签名、个人配置和测试截图仅保留在本地测试环境，没有打入 APK、源码或公开 Release。测试退出时恢复测试影片原有的进度记录。

## 范围

本次解决百度旁挂字幕下载被拒绝的问题，不通过豆包生成或替换已有字幕，也不改变其他网盘的画质权益。真实电视仍需要安装后验证。天翼杜比视界和夸克会员 4K 尚未通过，阿里原画继续暂缓。0.1.18 的在线更新修复继续保留。
