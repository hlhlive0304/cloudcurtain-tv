## 真实下载与安装：通过

1. 最终生产 APK（versionCode 17）读取公开清单，显示“当前已是最新版本”。
2. 用保留数据的旧版本测试引导包（versionCode 16）验证发现新版。该引导包仅用于测试，不发布；0.1.15 正式交付版没有更新入口。
3. 清除旧的更新缓存，实际从公开 GitHub Release 地址下载新版，没有注入测试响应或安装包数据。生产更新代码核对大小、SHA256、包名、版本与原签名；随后独立读取模拟器下载文件，再次确认其哈希与公开包一致。
4. 点击“安装新版”，显示 Android 系统安装确认界面；确认后从 versionCode 16 覆盖升级到 17。
5. 已安装 APK 的哈希与公开 APK 相同；升级前后的加密配置文件一致，网盘账号与已保存配置保留。未公开配置内容或私人配置摘要。
6. 升级后再次读取公开清单，正确显示最新版本。

## 网络条件与仍存在的播放限制

本机电脑通过已配置的系统代理访问 GitHub。模拟器首次直接连接 `github.com:443` 超时，更新页能显示失败并允许重试；公开清单仍可读取。随后仅在模拟器测试期间配置同一网络代理，真实公开下载与系统安装全部通过；结束后恢复模拟器原来的网络设置。此代理没有写入 APK 或仓库配置。

因此，电视在线更新需要可访问 GitHub 的网络。该结果不代表所有网络均可直连 GitHub；访问失败时可继续使用当前版或手动覆盖安装。
