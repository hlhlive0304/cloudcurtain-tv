# 0.1.22 上一集与下一集

2026-10-15，Android TV 11 / API 30 模拟器，沿用原测试账号与原签名；没有连接实际雷鸟电视。

## 行为

播放页进度条下方显示时间、当前序号和“上一集 / 下一集”；字幕、清晰度、音效、音轨、倍速、更多六个设置入口保留在下一行。菜单键显示控制栏，从设置入口向上进入有效的剧集按钮，左右选择、确定切换。

文件列表和电影墙提供当前文件夹及所属阿里空间；播放器只读这个文件夹的完整分页，排除文件夹、字幕和其他非视频文件，按文件名中的数字自然排序，避免 E10 排到 E2 前。目录读取上限为 100 页 / 10,000 个条目，未完成时不展示残缺队列；可在“更多 → 重新读取剧集”重试。当前视频不在目录、来源没有目录或网络失败时，不猜测相邻视频。

只在用户点击后解析目标视频地址，不预取全部剧集视频。切换前继续保留当前视频，解析失败时提示并允许重试；解析成功后保存旧视频进度，目标视频从头播放并保留当前倍速。每集分别加载自己的字幕，原画 / 兼容地址刷新保留目录上下文。首尾不循环，单文件目录两方向禁用；片尾不自动切集。旧播放页结束，返回选片页面不会逐集退回历史播放页。
