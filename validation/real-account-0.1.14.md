## 范围与限制

- 模拟器关闭音频输出；音效选择、保存、启用状态通过，不等于电视扬声器听感或 Atmos 解码验收。
- 清晰度选项来自账号实际返回的原文件和已完成转码。原文件是 4K，不代表网盘提供 4K 转码；模拟器无法解码某些原文件时使用兼容画质。电视实际能力仍需以设备解码器为准。
- 豆包识别片名并匹配真实候选，不是字幕数据库，不生成电影对白、时间轴或不真实的字幕链接。外部 OpenSubtitles 完整搜索/下载因没有服务密钥未验收。
- 本轮公开封面真实流程通过；TMDB 私人影片匹配因未提供 TMDB 密钥未验收。公开网站可能变更、限流或缺图，不承诺所有影片都有封面。
- 百度图库大量照片，旧有全盘扫描尚未完成；本次视频测试使用当前视频分类查询，不宣称其全量电影墙索引完成。
- 离线侧载安装包，没有部署在线更新服务或创建 GitHub 仓库；用户选择在 App 完成后再设置 GitHub。
- 账号、Cookie、模拟器数据、DPAPI 文件、签名密钥不进入交付；个人 API Key 仅加密资产与本机 Keystore 保存，不含明文密钥。个人导入码另行提供，不放入 APK 或源码 ZIP。
