## 原生直连结果

在 Android TV 11 模拟器，以较低版本号的测试引导包运行相同的新更新客户端；删除对应版本的下载缓存后执行真实公共网络更新。此测试验证新客户端，不能说明旧 0.1.16 的 Raw 客户端在同一网络已恢复。

| 检查 | 实测结果 |
| --- | --- |
| 网络条件 | 原生 ProxySelector 为 DIRECT；没有代理 |
| 读取公开清单 | 官方 API；842 ms；发现 versionCode 19 |
| 新下载公开 0.1.18 | 官方 API 下载；11,487,244 bytes；219,070 ms |
| 安装包验证 | 大小、SHA256、包名、版本号、签名全部通过 |
| 安装入口 | 实际 Android 系统安装确认界面出现 |
| 确认覆盖安装 | 系统显示 App installed；实际安装 versionCode 19 / 0.1.18-preview |
| 安装后 APK | 从系统安装目录读取副本，与候选及公开 APK 摘要完全相同 |
| 配置保留 | 单独一次受控覆盖安装，使用即时安装前后基线，保存的加密配置文件摘要完全相同 |
| 安装后账号验证 | 百度、夸克、阿里、天翼根目录请求全部通过，无需再次扫码 |
| 安装后更新检查 | 官方 API；843 ms；当前包与清单均为 versionCode 19 |

公开更新前进行过四网盘播放回归，其中接口会正常刷新登录凭据，旧基线的文件摘要因此发生变化。没有将该旧基线差异当作安装删除配置，也没有声称首轮摘要始终相同。即时基线的受控安装及安装后四账号目录读取确认了实际保留情况。
