# 云幕 TV 0.1.12 · 实际测试记录

日期：2026-10-10。官方 Android TV 11（API 30）模拟器，1280 × 720；使用真实安装的 APK 和用户此前扫码授权的四家网盘账号。APK 不包含测试账号、用户影片索引或临时播放地址。

## 已完成的验证

- 豆包使用用户确认的官方 Responses 接口及模型 doubao-seed-2-0-mini-260428。实际 APK 从个人加密配置导入密钥，退出测试进程后仍能读取；不再使用 chat/completions。实际片名 / 年份 / 中文候选匹配成功。请求 store=false；只发送清理后的片名、年份及实际字幕标签，不发送视频内容、文件 ID、路径或网盘凭据。
- 在阿里真实影片的播放器中点击智能匹配，出现推荐对话框，确认后实际下载并缓存网盘提供的 VTT 字幕，选中字幕轨道，视频进度继续前进。该验证不是伪造字幕 URL 或仅验证 HTTP 200。
- 阿里与夸克的清晰度来自账号实际授权且已完成的转码；不会展示无权限、待转码或仅供预览的链接。原文件仍可选，默认优先原文件，失败时有限次数恢复到最高可播放兼容转码。
- 保留阿里资源库 / 备份盘所属空间。播放器获取新画质、刷新地址和读取同目录字幕时沿用影片所属空间，避免切错盘。
- 阿里 / 夸克的实际影片验证包括初始画面和进度、两次清晰度选择、进度保留、快进到影片中部、退出重进与续播。另验证暂停中切换画质仍保持暂停、无效画质请求失败后原视频可恢复播放。夸克另外包含原文件不适配模拟器后的自动兼容恢复。
- 自动音轨策略在支持的主音轨中优先声道、采样率和码率，避开评论 / 解说音轨；音效默认原声。真实模拟器音频会话中的 Equalizer 人声增强启用状态已检查，切回自动原声后释放效果。音效不可用时保留原声，不假称 Dolby Atmos。
- 四家账号的真实目录读取回归通过；百度、天翼保持此前已经通过的播放流程。

## 自动检查

106 项单元检查：104 项通过，2 项需要扫码的旧在线单元检查按原配置禁用；扫码账号专项另在模拟器执行。没有失败项。Android Lint：0 errors，44 warnings。APK 签名沿用前版，可覆盖安装。

检查覆盖媒体请求来源与重定向、Cookie / 授权隔离、播放失败恢复、网盘返回的画质过滤、音轨选择、配置码解锁、API 请求格式、响应解析、无效候选和未完成响应拒绝等行为。

## 使用与范围

在“字幕与设置 → 导入我的豆包配置”输入随附文件中的 20 位个人配置码一次，之后凭据由本机 Android Keystore 保存。APK / 源码只有加密配置，解锁码与明文 API Key 均不在包内。配置文件与安装包分开保管。字幕匹配从播放器菜单进入。

本次阿里账号返回的最高在线转码标识为 720p；夸克该测试文件返回一档 360 × 202 的授权转码。清晰度选项取决于具体影片与账号，不能据此宣称实际测试了 4K 转码。原文件 4K / HDR、TrueHD / Atmos 等由电视和音响的实际能力决定。

模拟器关闭音频输出，音效 API 的启用检查不等于真实电视扬声器试听。没有直接连接雷鸟电视，不能替代该机型的解码验证。

OpenSubtitles 的外部字幕数据库搜索仍需要用户自己的 OpenSubtitles API Key；本次真实验收的是豆包推荐与网盘已有在线字幕。豆包不是字幕文件库，不凭片名虚构对白或字幕时间轴。

电影海报墙保留；用户尚未提供 TMDB 凭据，因此其真实影片在线封面匹配尚未验收，未配置时使用片名占位封面。
