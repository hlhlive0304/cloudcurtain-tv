# 0.1.17-preview：指定目录、海报识别与百度大影片

2026-10-11；Android TV 11 / API 30 / x86 模拟器，保留四个已登录测试账号。生产包版本号 18；APK SHA256：`5efdee142adb7ab249c5aba426bf797d3ed7dc32feee84320d4e68e614fb20e0`。公开 APK 与实际安装包字节一致，签名与 0.1.16 相同。测试只读取网盘文件，没有修改或上传影片。

## 修改

按每盘根目录的“电影、漫剧、电视剧”递归索引，按这个顺序进入分类目录。旧全盘扫描的课程、零散文件和旧断点会迁移；收藏、进度、账号保留。每次扫描最多 40 页，剩余目录通过“更新影片库 → 继续扫描”完成；可在扫描期间浏览已收录影片。四家目录均已读取通过；阿里一次返回 429，间隔后从断点继续通过，没有反复重试限流请求。

清理日期、剧场版编号、字幕组和画质标签；编号、日期和短缩写文件名使用所属影片文件夹；文件查询没有唯一结果时再以所属影片文件夹和年份查询。主标题或冒号后的副标题只有唯一候选、年份相符才自动匹配。修正查询后重新检查自动封面，手动封面保留；网络目录未收录、服务不可用或同名歧义仍可显示占位图。

百度原文件 ≥1 GiB 使用更大的启动／重新缓冲储备及有上限的媒体内存。有效视频数据持续下载的启动不再于 45 秒提前判定超时。正常登录接口验证完整 1080p／720p／480p 转码清单后才提供画质；没有会员或广告覆盖参数。自动模式遇到原画不能解码或持续缓冲可有限恢复兼容视频，保留进度和播放状态；明确选择“原文件”时不自动降画质。

## 验证边界

百度《玩具总动员5》原文件 54,198,232,169 字节（约 50.5 GiB），3840×2160 Dolby Vision Profile 7。原文件抽测和 Range 请求可读；该模拟器不支持其视频解码。**本次通过的是 1920×1080 兼容视频，不是 4K 原画。** 不把仅有声音、时间轴前进算作视频成功。

千兆接入速度不等于网盘当前视频线路的吞吐量；增加本机缓冲不能长期弥补持续低于影片码率的下载速度。真实电视的 Dolby Vision、音频和视频解码能力以及网络路径仍可能与模拟器不同。本次没有证明雷鸟 85R675C 上该文件的 4K 原画已经通过。

夸克测试账号尚未开通 SVIP，因此会员 4K 没有验收；天翼《复仇者联盟4》Dolby Vision 的模拟器限制保留。音效选择、字幕翻译、跳过片头片尾及原有更新实现沿用；本次没有新增这些功能的验收结论。
