# 云幕 TV 0.1.20 · 实验预览版

Android 6.0+ 电视播放器，为雷鸟 85R675C 等 Android 电视设计。百度、夸克、阿里、天翼在电视内扫码登录，不需要电脑、NAS 或 OpenList 中转。使用同签名 APK 覆盖安装，保留本机账号和设置。0.1.16 起提供 GitHub 在线更新入口，可从首页或设置中检查更新、下载并由系统确认安装。发布步骤见 ONLINE-UPDATES.md。

同时修复百度文件列表正常、字幕下载却报 -6 的短期网页会话问题：自动访问官方主页刷新一次，再读取同一份字幕；没有恢复时提供“打开百度官网”验证入口。已复现缺少 STOKEN 时的报错，并验证自动恢复后下载和中文显示。具体范围见 [0.1.20 验收记录](validation/update-subtitles-0.1.20.md)。

## 本版应用更新

更新清单来自本项目公开仓库，安装包存放于 GitHub Releases。下载后校验 SHA256、包名、版本号与原签名，安装前再复核；拒绝错误安装包、版本倒退及不可信服务器跳转。操作可取消；网络失败时保留当前软件，允许重试。首页、关于、诊断从实际安装包读取版本号。公开版不包含个人配置资产；覆盖安装仍保留已保存的网盘账号和豆包配置。

夸克测试账号尚未开通 SVIP（用户确认）；官方截图显示 4K、1080p 需要相应会员权益。本软件仅使用账号实际提供的画质，不把原文件分辨率等同于已获得的在线播放画质。天翼《复仇者联盟4》Dolby Vision 在模拟器仍未解码通过；这一限制不因本次在线更新功能而改变。

## 0.1.17 目录扫描与百度播放

电影墙按每个网盘根目录的“电影 → 漫剧 → 电视剧”扫描，并递归读取这三个目录里的影片；根目录散放的视频、课程及其他目录不会收进电影墙。首次打开会迁移旧的全盘索引，保留账号、收藏与播放进度。一次最多读 40 页，大目录可点击“更新影片库 → 继续扫描”。清理发行日期、剧场版编号、字幕组与画质标签；缺少片名或文件名缩写时，使用所属影片文件夹和年份查询。文件片名无唯一结果时再用所属影片文件夹查询，同名、年份不符或多结果时不自动错配。片名修正后重新匹配自动封面，手动选择的封面保留。网络海报库未收录的影片仍使用占位图，不伪造图片匹配。

同片名、年份、类别复用已确认的公共影片信息，多个剧集或同片不同网盘文件不重复请求；公开海报搜索至少间隔一秒，取消页面时停止后续补查。临时空结果短期缓存 15 分钟，保留已有合法匹配封面，不再把空结果缓存七天。可在“海报设置 → 重新尝试自动匹配”重试未匹配影片。测试期间公开服务曾返回空结果，最终跨网盘验收复用并校验真实海报缓存，不代表所有未缓存影片当时均能联网匹配。

百度大原文件增加启动和重新缓冲的储备，媒体缓冲占用按电视应用内存限制；仍在下载的正常启动不会在 45 秒时被误判超时。清晰度菜单加入账号实际返回的 1080p / 720p / 480p 在线转码，自动模式遇到原视频无法解码或持续缓冲时有限切换到兼容视频；明确选择“原文件”时不自动降画质。视频轨道不能解码时及时说明，不把有声音、时间轴前进当作视频播放成功。

《玩具总动员5》测试原文件为约 50.5 GiB、3840×2160 Dolby Vision Profile 7；原文件分辨率和成功播放的转码分辨率分别记录。完整验收见 [0.1.17 验收记录](validation/folder-baidu-0.1.17.md)。4K 杜比视界原画仍取决于电视解码器和网盘视频线路速度，模拟器的兼容画质通过不代表原画通过。

## 此前修正与验收限制

按用户要求暂缓阿里原画 4K 的对接。天翼文件会话失效时恢复官网 SSO，再验证新会话后保存；播放前验证门户签发的 HTTPS CDN 并直接使用该地址，避免后续读数据反复经过门户；播放地址返回 401/403/404/410 时，自动重取一次同清晰度地址并保留进度。夸克原文件解码失败或下载停滞时，自动模式使用账号实际提供的兼容线路；切换兼容线路与后续地址过期使用独立的次数上限。设备解码器初始化失败时尝试系统其他可用解码器。

夸克《复仇者联盟4》兼容线路实测为 480×202 AVC，原文件为 HEVC 4K，原下载抽测约 117 KiB/s；不把兼容播放标成 4K 原画。天翼同片是 3840×2020 Dolby Vision dvhe.08.06，连续网络读取约 14.7 MiB/s，但模拟器解码失败；本版不能保证此格式在任何电视上播放。天翼普通 H.264 文件播放、快进、片尾和续播已实测。完整记录随包提供。

## 文件浏览

四家网盘新增类型和来源筛选、名称/类型/修改时间/创建时间/大小排序及正倒序、分栏/列表/图标/大图四种视图。每盘记住选择。筛选和排序针对已经加载的本页文件，保留文件夹用于进入下一级；来源未知时不伪造分类。分栏显示最近几级目录，重新选择父目录会更新后续列。

电影墙每页最多 24 张卡片，按可见区域加载封面，限制图片与后台任务数量；真实账号和 3000 条索引压力测试通过。豆包翻译可使用已有文本字幕或选中的 PGS 字幕裁片，需主动开启；仅发送字幕区域，快进、暂停和关闭后同步停止旧任务，结果缓存于本机。

## 播放与操作

播放页底部提供字幕、清晰度、音效、音轨、倍速、更多六个入口。遥控器菜单键显示控制栏，左右键选择入口，确定键打开，返回关闭；控制栏隐藏时左右键快退、快进。布局按实际窗口与系统字体适配，长列表可以滚动。

“更多 → 跳过片头 / 片尾”分别填写时长（秒）。两个选项默认均为 0、关闭；只有保存后才生效，按当前视频单独保存，也可“全部关闭”。片头跳到指定时长，片尾到达设置区域后停止播放。手动退回片头不会反复强制跳过。未知时长或片头片尾设置超过影片长度时不自动执行。

本版换用深蓝、青绿色的云朵 / 影院幕布 / 播放符号图标，并同步电视启动横幅。素材由内置 image_gen 工具生成，提示词与制作说明见 validation/icon-generation.md。

## 清晰度与音效

默认优先原文件和最高可解码主音轨。百度、阿里、夸克列出账号实际提供的已完成转码；原文件标签使用真实视频宽高，宽银幕 3840×1608 也标记 4K。原文件是 4K 不代表网盘同时提供 4K 在线转码。切换画质重新获取临时地址并保留进度、暂停状态；原文件无法解码或长时间不出画面时，有限地恢复到账号可用的兼容视频，不无限刷新。

音效可选普通音效、人声增强、超重低音、环绕音效；默认自动优先最高音轨并保留原声。使用系统 Equalizer、BassBoost、Virtualizer，设备拒绝启用时提示并保留原声。虚拟环绕不代表杜比全景声，不能把普通音轨变成 Atmos。模拟器关闭音频输出，已做选择与启用状态检查，不能替代电视扬声器试听。

## 内嵌字幕与在线匹配

可选择内嵌字幕、网盘提供的同文件字幕、同目录字幕、本地文件或字幕直链。优先可解码的完整中文字幕，用户手动关闭或切换后尊重选择。阿里兼容视频缺少内嵌字幕时，独立读取平台返回的同文件字幕。夸克兼容视频缺少原字幕时，尝试只解码原文件的字幕轨道；读取原文件仍消耗网络带宽，大文件和快进后可能需要重新加载。文件本身只有英语、法语、西班牙语字幕时，不会伪造中文字幕。

在线字幕默认先用豆包识别片名并推荐实际候选，不需要先配置 OpenSubtitles。豆包不提供电影字幕数据库，不会凭片名编造对白、时间轴或下载链接；没有中文字幕候选时说明原因。OpenSubtitles 外部搜索是可选独立入口，需要自己的服务密钥和额度。

豆包使用官方 Responses 接口与 Mini 模型；仅用户点击时发送清理后的片名、年份和候选标签，关闭响应存储。个人 API Key 在电视设置中填写并存入 Android Keystore；此前已导入的配置覆盖安装后保留。公开源码和 APK 不含个人密钥、配置资产、配置码或测试账号。

## 电影墙与封面

电影墙只展示指定三个目录中的影片，可分别筛选电影、漫剧、电视剧，也可搜索、收藏、继续观看和选片。首次扫描每盘最多 40 页，可以继续扫描；重新扫描移除旧索引。扫描只读，不上传或修改网盘文件。索引不保存临时视频地址。

默认优先使用豆瓣电影的公开封面；维基百科 / Wikimedia 为补充图片和简介来源，无需海报 API Key；按准确片名与年份唯一匹配时自动缓存，未匹配到或有同名版本时保留占位图。在影片详情可“匹配 / 更换封面”，也可“豆包匹配封面”：豆包先识别片名与年份，再查询网络真实图片，由你确认正确影片。封面图片来源按钮可查看原图页面及许可。网络数据不一定覆盖全部影片。

TMDB 是可选海报来源：在“海报设置”配置自己的 TMDB v3 API Key 或 Read Access Token 后，可搜索封面、评分和简介。没有用户 TMDB 密钥，TMDB 私人影片自动匹配尚未验收。本版不上传或修改网盘文件，更新封面仅保存到电视本机。

## 测试与范围

本版实测结果和限制见 validation/real-account-0.1.15.md。测试使用官方 Android TV 11 模拟器与用户扫码的真实账号；测试 APK 不随交付安装包发布。单元检查、网络数据读取、实际出画面和字幕显示分别记录，不用解析成功代替播放成功。模拟器不能解码的杜比视界等格式不能据此保证雷鸟真机播放。

四家网盘支持退出登录、更换账号；单盘退出保留其他账号和豆包配置。诊断仅保存在本机，记录阶段、异常类别、HTTP 状态与代码位置，不保存账号、片名、令牌、二维码或响应正文。认证头仅发送到对应服务，测试账号、模拟器数据、签名密钥不进入 APK 或源码包。
