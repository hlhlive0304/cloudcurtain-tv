# 0.1.20 更新提速与百度字幕会话

测试平台为保留四个网盘账号的 Android TV 11 模拟器。本次没有连接或操控用户的雷鸟电视，不代表实际电视的网络或硬件验收。

## 更新下载

- 同一份公开 0.1.19 安装包，11,489,875 bytes。旧客户端直接连接 GitHub 官方资产存储为 288,120 ms；新客户端实际更新页面直接连接为 83,509 ms，完整 SHA256、包名、版本及原签名复核通过。两次均无代理，但不同时间的网络状况也会影响结果；不承诺每台设备固定提速倍数。
- 官方服务器返回 206 / Content-Range，先探测 1 byte，再使用 4 个独立连接读取互不重叠的范围。仅访问现有可信官方地址。分段大小、范围、编码与强 ETag 必须正确；最终完整摘要校验仍是安装前提。
- 并发、乱序拼接、服务器忽略 Range、连接截断后回退、错误范围、混合版本、损坏分段、取消和清理都有回归测试。取消及回退需等所有分段停止后才清理或开始新的下载。
- 下载页增加大小、速度、剩余时间。旧版下载安装本版这一次仍使用旧下载器，安装后才获得新的下载流程。

## 百度字幕

- 用户反馈 0.1.19 文件列表正常，但《希望》的“简中.srt”报百度 -6。模拟器初始完整会话可正常读取。
- 在内存隔离请求中省略 STOKEN 后，文件信息 errno=0、下载会话变量 errno=-6；访问正常官方主页后恢复为 0。没有修改保留的账号 Cookie。
- 再使用真实 CookieManager 仅移除 STOKEN，根目录仍返回 11 项，变量接口复现 -6。实际 Subtitles.cache → CloudApi.resolveSubtitle 自动刷新流程恢复会话，读取 87,745 bytes 的有效中文时间轴；主登录保留。没有清空账号、伪造字幕或调用豆包额度。
- 实际播放器菜单选择该 SRT 后显示中文，显示内容与原字幕时间轴相符；中段快进、持续播放、关闭、重新选择通过。
- 同时验证真实 ASS 文件 107,489 bytes 的菜单加载、中文显示、时间轴、快进和重新选择。早期辅助测试未等待字幕轨道完成准备，或在快进缓冲未结束时立即判断播放停滞；保留失败日志，补充准备及继续播放的条件后通过，生产字幕解析流程没有更改。
- 会话未恢复时停止重试，提供百度官方网页验证入口；其他接口错误不会无限重试或绕过权限校验。
