# 0.1.18-preview：应用更新超时

2026-10-11。生产代码来自公开 0.1.17 基线，仅修改更新客户端、更新页面和版本号；没有合入仍在排查的天翼杜比视界及夸克原画开发改动。模拟器为 Android TV 11 / API 30，使用保留的四网盘登录配置。以下直连测试没有使用代理。

## 问题与修改

用户电视上的应用版本为 0.1.16-preview，检查更新显示 `timeout`。另一张截图为电视固件更新，它与本应用的 GitHub 更新入口分别工作。在测试网络中原 Raw 清单地址直连超时，官方 Contents API 同一份清单成功返回。

现在优先使用官方 Contents API 读取清单；连接或 HTTP 失败时尝试原 Raw 地址。安装包优先通过官方 Release API 校对对应标签的资产地址、大小和摘要，再从资产接口及官方 CDN 下载；连接失败时尝试原 Release 下载地址。两条线路都失败时显示中文说明，用户可以取消、重试或通过“手机扫码下载”打开本项目发布页。

大小、SHA256、APK 包名、版本号、签名及 HTTPS 跳转范围校验继续保留。成功返回但格式或身份无效的数据不会通过换线路绕过验证。不在电视存储 GitHub 令牌，也不发送网盘 Cookie 或授权头。

## 限制及安装方式

旧版检查更新若已经超时，需要先手动覆盖安装 0.1.18 一次以获得新客户端。无需卸载原应用；覆盖安装保留本机账号和设置。若官方 API、Raw、官方 CDN 在电视网络中都不可达，仍需要手机下载后传到电视安装，本版不承诺任何网络始终可达。

以上是模拟器验证，尚未直接连接用户电视进行更新或解码测试。天翼杜比视界原片及夸克会员原画 4K 仍未通过；夸克测试账号没有相应 SVIP 权益；阿里原画继续按要求暂缓。普通 H.264 或兼容视频通过不能代表原画 4K 或杜比视界通过。
