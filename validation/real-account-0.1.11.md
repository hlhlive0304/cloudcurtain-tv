## 封面服务范围

TMDB 搜索使用用户自己的 v3 API Key 或 API Read Access Token，在“海报设置”加密保存，独立客户端只连接官方 API。图片客户端仅允许官方 TMDB 海报路径，不携带认证或网盘凭据。不把网盘路径、ID、Cookie、账号或临时媒体地址发给 TMDB。明显相机文件名不自动匹配。

自动匹配只接受唯一标题 / 年份吻合的结果，支持中文简介、年份和评分。模糊、同名电影或错误年份需要用户在详情里手动纠正。无密钥 / 未匹配 / 无网络时显示片名占位卡，播放仍可使用。

当前没有用户 TMDB 密钥，真实搜索、自动匹配及手动候选搜索尚未联机验收。单元测试覆盖标题解析、数字电影名、剧集父目录回退、重名消歧、API 认证请求隔离、非法海报路径、响应大小限制；官方示例图片测试不能代替真实电影匹配。
